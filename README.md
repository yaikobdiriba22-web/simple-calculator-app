# Calculator Mobile App

A simple calculator mobile app built with React Native and Expo.

## Run it locally

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Open it in:
   - Expo Go on your phone
   - Android emulator
   - iOS simulator

## Features

- Basic arithmetic operations
- Clear and backspace
- Decimal support
- Keyboardless mobile-friendly button layout
- Works on Android and iOS

## Notes

This project is set up as a mobile app using Expo so it can be previewed on a real device or emulator without needing a browser.
